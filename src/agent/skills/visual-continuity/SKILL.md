# 相邻镜头画面一致性

多个镜头连在一起时，观众对「跳变」很敏感。检查相邻镜头的画面一致性，发现跳变按**调色 → 取景 → 换素材**的顺序修，从轻到重、能不换素材就不换。

## 四个检查维度

| 维度 | 看什么 |
|---|---|
| 颜色基调 | 相邻镜头色温、明暗、肤色是否突变 |
| 人物朝向 | 同一人/同一对象在相邻镜头是否突然换边、换朝向 |
| 构图重心 | 主体在画面中的位置是否跳动、留白是否失衡 |
| 运动方向 | 运动方向（如左→右）跨切点是否连续 |

## 步骤

1. **抽相邻帧**：`view_timeline_frames` 按切点抽相邻镜头的首尾帧，成对比较。
2. **定位跳变**：按上面四维逐个核对，记录哪个维度、哪两个镜头之间跳。
3. **修——先调色**：颜色基调问题用 `inspect_color` 看数值，`auto_grade` 统一基调；肤色、色温尽量先从这里解决。
4. **修——再取景**：构图重心/朝向问题先用 `auto_reframe` 或 `edit_item` 调整取景、缩放、位置，不动素材本身。
5. **修——最后换素材**：前两步解决不了才换。`remove_item` 删掉跳变的镜头，`search_stock_media` 或已有素材（`manage_media_pool`）补一个能接上的。
6. **复看**：修完再 `view_timeline_frames` 抽相邻帧确认不再跳。

## 注意事项

- **顺序别倒**：先调色再取景最后换素材；能调色解决就不换素材。
- **发现跳变才修**：一致性是手段不是目的，别为「统一」把每个镜头都抹平。
- **同一个人跨镜头一致**靠复用同一素材（定妆图/同一条镜头），换脸是最明显也最该避免的跳变。
- 运动方向的连续性要结合 `detect_scenes` 的镜头边界一起看，别在转场处误判。
