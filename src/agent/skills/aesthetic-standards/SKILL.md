# 全片美学准则与反 AI 味清单

本技能给「片子要好看、别一眼看穿是 AI 套模板做的」提供一套可执行准则和一条负面清单。做完片后用它在交付前过一遍。

## 八个准则面

| 面 | 准则 | 用什么核对 |
|---|---|---|
| 层级版式 | 一个画面只突出一个重点，字号/粗细/留白拉开主次 | `view_timeline_frames` 抽帧看 |
| 色彩 | 全片一个色彩家族，肤色自然，不用高饱和撞色 | `inspect_color`、`auto_grade` |
| 字幕 | 断句整句、贴底不贴脸、不挡主体 | `read_captions` |
| 动效 | 动效为信息服务，不无谓飞入飞出 | `view_timeline_frames` |
| 构图 | 主体清晰、留白合理、重心不晃 | `view_timeline_frames` |
| 平台安全区 | 适配目标画幅，关键信息不进安全区边缘 | `auto_reframe` 适配画幅后核对 |
| 节奏转场 | 转场有意图，卡点跟着音乐 | `detect_beats` |
| 交付自检 | 导出前五项质检 | `verify_export` |

统一视觉语言用 `manage_design_style` 定，别一段一个风格。

## 反 AI 味负面清单（逐条自查）

- 机械匀速：全程一个节奏，没有呼吸、没有停顿、没有强调。
- 过度对称呆板：所有字卡都居中、所有镜头都一个构图。
- 字幕贴脸/过密：字幕压在人物脸上、一次塞满整屏文字。
- 无意义动效：转场、放大缩小只为「显得有在做动效」。
- 色彩失真：过度磨皮、荧光绿肤色、无来源的冷暖跳变。
- 模板感：片头片尾和中间内容各说各话，没有统一语言。
- 空镜头堆砌：画面和说的话对不上，只是「有画面」。

## 交付前自检步骤

1. `view_timeline_frames` 抽关键时刻帧（片头、转场、强调点、片尾）。
2. 对照八个准则面 + 负面清单逐条过，记下违规点。
3. 违规点用对应工具修：色彩 `auto_grade`、字幕 `read_captions` 核对断句、画幅 `auto_reframe`、卡点 `detect_beats`。
4. 修完 `verify_export` 做最终质检再 `submit_export`。

## 注意事项

- 美学服从目标：`brief` 里的受众和平台优先于「好看」；竖屏平台按竖屏安全区，别拿横屏习惯套。
- 负面清单是自查表不是硬删清单——先定位再修，别为「去掉 AI 味」把有意图的设计也抹了。
