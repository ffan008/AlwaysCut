# 青橙电影感组合

当用户说「电影感 / 大片感 / 影视感 / 像电影一样 / 高级感」时使用本技能。核心是把普通素材做成青橙（teal-orange）电影色调：暗部偏青、高光肤色偏橙，再叠加黑边（letterbox）、暗角（vignette）和缓慢推近（slow push-in），让画面有叙事感。

## 什么场景用

- 旅行、人像、城市、产品短片想有「大片质感」
- 用户抱怨画面「太平、太普通、没有电影感」
- 需要统一的青橙电影基调覆盖整条时间线或某几段

## 步骤

1. **先测数值**：对目标片段调用 `inspect_color` 拿到当前帧的黑白点、溢出比例、分段暖冷/绿品平衡和 12 档色相直方图。不要凭截图目测，先有数字再动手。
2. **分析现状**：调用 `auto_grade`（mode 为 `analyze`）读取当前滤镜状态，确认已有哪些调色滤镜，避免重复叠加。
3. **套青橙基调**：调用 `auto_grade`（mode 为 `apply`）落地电影感技术调色（内部走 `setFilters`）——压低暗部并向青偏移、把肤色/高光推向橙，控制整体对比与饱和度。
4. **加黑边与暗角**：调用 `manage_effects` 给目标片段加 letterbox 黑边和 vignette 暗角，黑边比例与暗角强度以「不遮挡主体、不压暗人脸」为准。
5. **缓慢推近**：调用 `edit_item` 对目标片段加缩放/位移动画，做成从 100% 到约 103–105% 的缓慢推近，时长覆盖整段，缓入缓出。
6. **预览回看**：调用 `view_timeline_frames` 在关键帧（开头、中间、结尾）确认青橙平衡、黑边与暗角自然、推近不穿帮。

## 注意事项

- 青橙要克制：暗部别死黑、肤色别变蜡黄，`inspect_color` 报的溢出比例超过阈值就回调强度。
- 黑边会裁剪有效画幅，主体构图要提前确认不被裁掉；人脸/字幕不要落到黑边内。
- 缓推要缓，幅度过大会显生硬，且不要和黑边/暗角叠加导致四周发虚。
- 只对用户指定的片段或整轨生效，不要悄悄改动无关素材。

## 交付前自检

- [ ] `inspect_color` 已看过数值，青橙方向正确、无大面积溢出
- [ ] `auto_grade` 已 apply 且未重复叠加同类滤镜
- [ ] 黑边、暗角、缓推已就位，主体与人脸完整
- [ ] `view_timeline_frames` 已确认关键帧画面自然
