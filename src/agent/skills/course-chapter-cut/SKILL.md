# 长教程 / 网课章节划分（Course Chapter Cut）

## 适用场景

把长教程 / 网课 / 录课素材按章节划分，删掉口误与停顿，配字幕和章节标题。

## 工作流

1. 通读：用 `read_transcript` 通读全文，找出知识点边界。
2. 标章节：用 `manage_markers` 在每个章节起点打标记。
3. 清理：用 `clean_script` 批量删口误、压缩长停顿。
4. 组织：用 `read_script` + `apply_script` 按章节整理、删除重复讲解。
5. 加标题：每章开头用 `edit_item` 放章节标题卡，`set_item_timing` 控制显示时长。
6. 配字幕：用 `edit_captions` 为全片配字幕。

## 注意事项

- 按完整知识点切章，不要在一句话中间打断。
- 章节标题简短（2-5 字为宜），放在不遮脸、不遮字幕的位置。
- 保留必要的衔接语，删重复但别删掉逻辑。

## 交付前自检

- 每章开头有清晰章节标题，标题与内容对得上。
- 字幕与讲解同步。
- 章节边界处节奏自然。
