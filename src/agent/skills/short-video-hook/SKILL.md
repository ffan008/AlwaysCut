# 短视频开头钩子（Short Video Hook）

## 适用场景

用户反馈「开头不抓人 / 开头重剪」时，把最强镜头、悬念大字、快切音效编进前 3 秒，让观众 3 秒内停下来。

## 工作流

1. 找最强镜头：用 `find_highlights` 找出全片最有冲击力的镜头 / 高光。
2. 找悬念句：用 `read_transcript` 挑出最悬念 / 最有冲突的一句话。
3. 重组开头：用 `split_item` / `move_item` 把最强镜头和悬念句提到时间线最前。
4. 加悬念大字：用 `edit_item` 在前 3 秒放大字悬念卡。
5. 加音效：用 `add_audio` 加 riser / 快切音效强化节奏。
6. 收紧节奏：用 `remove_silence` 或 `edit_gap` 去掉开头拖沓的停顿。

## 注意事项

- 前 3 秒要画面 + 文字 + 声音三重钩子齐发，缺一不可。
- 悬念大字要短、要制造信息差，别把答案剧透在开头。
- 开头节奏要快，别让空镜或长停顿占了前 3 秒。

## 交付前自检

- 开头 3 秒内有强镜头、悬念文字、音效，节奏快。
- 悬念与正片内容真实对应，不标题党。
