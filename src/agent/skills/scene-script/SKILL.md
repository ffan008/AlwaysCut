# 把片子固化成可复用剧本文本

要「把这条片子的结构存下来以后复用」「改几句话/改时长后同步回时间线」时，走剧本体系：先把成片读成文本，改文本，再一次性应用回时间线。

## 步骤

1. **读成文本**：`read_script` 拿到当前时间线的剧本文本（含 `[sN]` 片段行、词级内容、时长线索）。这就是片子的可复用文本形态。
2. **固化模板**：把剧本整理成可复用结构——记录段落顺序、每段的关键句、大致时长、配了什么画面/字幕。同一结构存进项目文档（`write_project_doc`，如 `treatment` 或带后缀变体），作为「这一类的模板」。
3. **改词改时长**：在剧本文本上改词、删句、调顺序、压时长。改的是**完整语义单元**（整句/整段），别硬拼半个句子。
4. **同步回时间线**：`apply_script` 把改后的剧本应用回时间线；失败则读回当前文本修复再应用。
5. **核对**：`view_timeline_frames` 抽帧确认画面与改后文本一致，`read_captions` 核对字幕跟着变了。

## 注意事项

- **文本即真相**：一切口播内容的选段、删改、复用、重排都在剧本里做，不要用 `split_item`/`edit_item` 去按秒手工切口播——那会脱离编辑面、易错位。
- **改词后重新对位**：换了词、换了配音，用实测词时间重新对齐画面和字幕，不靠估。
- **重写不是追加**：模板文档同名覆盖，永远是「现在的结构」，别在文档里堆历史版本。
- **固化成文本是为了复用**：同一结构再出第二版（另一平台、另一时长）时，从剧本/模板改起，而不是重新剪一遍。
