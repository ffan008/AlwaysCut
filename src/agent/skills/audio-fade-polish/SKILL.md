# 音频淡入淡出抛光

当用户说「结尾太生硬 / 声音突然断 / 开头太突兀 / 有咔哒声 / 音量突变」时使用本技能。核心是给音频做平滑的淡入淡出：片头淡入、结尾随画面归零、中间消除音量跳变与咔哒，让声音进出自然。

## 什么场景用

- BGM 开头突然响起、结尾戛然而止
- 剪辑切口处出现「咔哒」爆音或音量跳变
- 需要声音随画面渐入渐出、收尾干净

## 步骤

1. **盘点音频**：调用 `list_audio` 列出所有音频片段，标记需要淡入淡出的开头、结尾，以及有咔哒的切口。
2. **片头淡入**：调用 `edit_item` 给每条音频开头加短淡入（通常 0.3–1 秒），让声音平滑进入。
3. **结尾随画面归零**：调用 `edit_item` 给结尾加淡出，时长参考画面收尾节奏（通常 0.5–2 秒），让声音随画面一起归零，不留硬切。
4. **消除中间咔哒**：对切口处音量跳变或爆音，调用 `edit_item` 做微交叉淡入淡出或音量包络，压掉「咔」声。
5. **回听自检**：调用 `view_timeline_frames` 或 `verify_export` 回听开头、结尾和每个切口，确认无突兀、无咔哒、归零干净。

## 注意事项

- 淡入淡出时长要匹配节奏：抒情慢片可稍长，快节奏短视频要短，拖太长会显拖沓。
- 结尾归零要和画面一致，不要画面还停在内容上声音就没了，也别画面黑了声音还在。
- 消咔哒优先用交叉渐变，别靠硬切再补淡入（可能反而引入新咔哒）。
- 只处理用户指定的音频段，不擅自动 BGM 与音效的混音关系。

## 交付前自检

- [ ] `list_audio` 已标记开头、结尾与咔哒切口
- [ ] 片头淡入、结尾淡出已用 `edit_item` 加好
- [ ] 结尾声音已随画面归零，无硬切
- [ ] 中间切口已消咔哒，回听自然
