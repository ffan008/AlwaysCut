# 街访成片（Street Interview）

## 适用场景

把「同一问题问多个路人」的街访素材剪成成片：一问一答成节拍，最有意外感的一条留到最后，补一句总结收尾。

## 工作流

1. 读素材：用 `read_transcript` 找到「问题」和每个路人的「回答」。
2. 建节拍：按「问题 → 回答」组织成一问一答的节拍，用 `read_script` 整理顺序，`apply_script` 落回时间线。
3. 清理：用 `clean_script` 去路人口误和过长停顿。
4. 排序：把最有意外感 / 最出彩的一条放到最后，前面逐步铺垫。
5. 收尾：补一句总收——用 `read_script` 拉出主持人 / 旁白的总结语，或加一句字幕卡收束主题。
6. 配字幕：用 `edit_captions` 给路人回答配字幕。

## 注意事项

- 问题是否在每条前重复出现由结构决定，避免单调，也避免丢失语境。
- 保留每条回答的完整意思，不要剪断路人没说完的话。
- 意外感要靠前面的「正常回答」来反衬，不要每条都夸张。

## 交付前自检

- 一问一答节拍完整，节奏统一。
- 最后一条是全片最有冲击力的回答。
- 收尾句能把主题收回来。
