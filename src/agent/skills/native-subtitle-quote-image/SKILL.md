# 字幕金句长图（Native Subtitle Quote Image）

## 适用场景

从视频 / 时间线里挑出金句，取真实帧，生成一张可预览、可保存的 JPG/PNG 语录卡（金句长图）。与 `video-thumbnail-generator`（做视频封面）不同，本技能产出的是「金句 + 真实帧」的语录长图，用于分享、发帖、配图。

## 工作流

1. 挑句子：用 `read_transcript` 或 `read_captions` 从视频里挑出最有价值的金句。
2. 定位帧：用 `find_transcript` 定位该句的时间点（含逐词时间戳），找到对应画面。
3. 取真实帧：用 `view_timeline_frames` 抓取该时间点的真实画面帧。
4. 合成语录卡：在真实帧上叠加金句文字与色块衬底，输出 JPG/PNG，保持真实帧不造假。
5. 保存预览：把生成的语录卡保存到可预览位置，交给用户确认后存档。

## 注意事项

- 必须用真实帧，不用凭空生成的假画面。
- 金句文字要准确对应原话，不擅自改写。
- 与封面区别：封面是「标题 + 画面」的发布封面，语录卡是「金句 + 画面」的分享长图。

## 交付前自检

- 帧是真实画面，金句与视频原话一致。
- 图片为 JPG/PNG，可预览、可保存。
- 文字可读、对比度足够。
