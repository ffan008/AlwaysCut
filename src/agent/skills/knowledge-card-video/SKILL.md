# 知识卡片风口播（Knowledge Card Video）

## 适用场景

口播讲解知识点时，用大字要点卡片 + 色块衬底强化关键信息，做成知识卡片风格。

## 工作流

1. 提炼要点：用 `read_script` 通读口播稿，提炼每条要点（短标签 / 数字 / 关键词，不是整句）。
2. 定位时间：用 `find_transcript` 找到每条要点出现的时间点。
3. 放衬底与卡片：用 `edit_item` 放置色块衬底和大字要点卡片，位置避开说话人脸部和字幕区。
4. 控制时长：用 `set_item_timing` 让卡片在该要点讲完时退出。
5. 反复检查：用 `view_timeline_frames` 确认卡片可读、不遮挡。

## 注意事项

- 卡片内容是短标签，不要放整句口播文字。
- 色块与文字对比度足够，移动端小屏可读。
- 卡片位置固定统一，形成一致的知识卡片风格。

## 交付前自检

- 用 `view_timeline_frames` 检查卡片可读、不遮脸、不遮字幕。
- 每张卡片与对应口播要点时间对齐。
- 视觉风格统一。
