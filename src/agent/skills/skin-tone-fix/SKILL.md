# 定向修肤色

当用户说「人太黄 / 脸太黑 / 肤色不好看 / 脸色蜡黄 / 气色差」时使用本技能。核心是只针对肤色做定向校正——去黄、提亮面部，同时尽量保持背景不受影响。

## 什么场景用

- 口播、访谈、人像、直播切片里人物肤色发黄发暗
- 用户要求「把人调白一点、脸色好一点、别动背景」
- 混合光源导致肤色偏色、蜡黄

## 步骤

1. **先测数值**：调用 `inspect_color` 看当前帧的暖冷/绿品平衡与肤色所在色相档，确认偏黄还是偏暗。
2. **分析现状**：调用 `auto_grade`（mode 为 `analyze`）读取现有滤镜，避免和已有调色冲突。
3. **定向去黄提亮**：调用 `auto_grade`（mode 为 `apply`）落地肤色校正（内部走 `setFilters`）——只对肤色色相区间降黄、提亮，把肤色拉向自然的橙粉，尽量不动背景的冷色与中性色。
4. **预览回看**：调用 `view_timeline_frames` 在人物出现的关键帧确认肤色自然、背景未明显偏移。

## 注意事项

- 定向是核心：肤色要自然红润，不能提成惨白或蜡黄，`inspect_color` 的暖冷平衡作为判断依据。
- 背景尽量不动；如果背景与肤色色相接近，优先保人脸，其次才微调背景。
- 多段素材肤色可能不一致，逐段检查并统一，别只改一段。
- 只处理用户指定的片段或整轨，不改构图与其它元素。

## 交付前自检

- [ ] `inspect_color` 已看过数值，偏黄/偏暗方向已确认
- [ ] `auto_grade` 已 apply，肤色去黄提亮、背景基本不动
- [ ] 各片段肤色统一自然
- [ ] `view_timeline_frames` 已确认关键帧人脸观感良好
