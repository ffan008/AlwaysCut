# 口播包装（Talking Head Packaging）

## 适用场景

口播视频讲到步骤、流程、数据、产品演示等「需要看画面」的内容时，把说话人主镜头缩进角落圆角小窗（PiP），用 B-roll/插画铺满全屏承担视觉重点；该段落讲完后，说话人再切回全屏。

## 工作流

1. 通读口播稿：调用 `read_script` 定位需要视觉包装的段落（步骤 / 流程 / 数据 / 产品）。
2. 定位时间：用 `find_transcript` 找到这些句子在时间线上的起点与终点，确定全屏 B-roll/插画的覆盖区间。
3. 看画面：用 `view_timeline_frames` 确认说话人当前构图，找出可放小窗的角落（避开脸、手势、字幕）。
4. 缩小说话人：用 `edit_item` 把主镜头缩放并移动到角落小窗，设置圆角；也可用 `apply_layout` 套 PiP 布局。
5. 铺全屏底：用 `edit_item` 把 B-roll/插画放到该区间并铺满全屏，作为底层视觉。
6. 切回全屏：段落结束时用 `split_item` 或 `set_item_timing` 让说话人恢复全屏。

## 注意事项

- 小窗放角落，避开说话人脸部和字幕区，圆角默认 24-36。
- B-roll/插画必须真实支撑口播内容，不是随意填充。
- 不要在第一 / 最后 3 秒切走说话人。
- 用 `undo_last_change` 回退不合适的缩放或位置调整。

## 交付前自检

- 用 `view_timeline_frames` 检查小窗不遮脸、不遮字幕，B-roll 可读。
- 每个包装段落讲完后能自然切回全屏。
- 覆盖区间时长与对应口播句子的时间对齐。
