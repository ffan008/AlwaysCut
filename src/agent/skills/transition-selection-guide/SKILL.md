# 转场选型决策树（Transition Selection Guide）

## 适用场景

用户要在切口加转场，或某个切点该不该转场、该用哪种转场拿不准时。核心原则：**转场表达语义，不是装饰**——先判断前后两个镜头的关系，再选转场类型，最后才考虑风格。

## 决策树

1. **先问语义**：这个切点前后是——
   - **因果/推进**（因为 A 所以 B）→ 用「动作匹配转场」或直接硬切，让动作惯性带过去。
   - **并列/罗列**（都是同类）→ 用「擦除 / 滑动 / 推近」等中性转场，统一即可。
   - **转折/对比**（A 与 B 相反）→ 用「闪白 / 抽帧 / 故障」等有断裂感的转场，把对比显性化。
   - **时间跳跃**（过了很久 / 倒叙）→ 用「叠化 / 淡入淡出 / 表针」等时间性转场。
   - **场景切换**（换地点/换人）→ 用「滑动 / 推拉 / 转场字卡」明确切场。
2. **再问强度**：信息密度高、节奏快的段落少用转场（用硬切保节奏）；节奏慢、情绪浓的段落才用柔和转场。
3. **最后定风格**：10 种视觉转场（叠化/擦除/滑动/推近/闪白/抽帧/故障/翻页/镜头光晕/缩放）＋ 3 种换字转场（地点卡/时间卡/章节卡），选与整片气质一致的。

## 工作流

1. 用 `view_timeline_frames` 看切口前后两帧，判断语义关系。
2. 按决策树选转场类型，用 `manage_effects` 或 `browse_library` 找到对应转场特效。
3. 用 `edit_item` 把转场应用到切口，设合适时长（视觉转场 0.2–0.5s，换字卡 0.6–1s）。
4. `view_timeline_frames` 回看转场是否流畅、是否遮住关键画面。

## 注意事项

- 同一条片子里转场要成系统：同一类切口用同一种转场，不要每刀换一个。
- 转场别抢戏：默认时长内完成，不要让观众「看到转场本身」。
- 换字转场（地点卡/时间卡）是信息载体，文字要准确、不遮挡人脸和字幕。

## 交付前自检

- [ ] 每个转场都对应明确的语义关系，不是随手加的
- [ ] 同类切口转场统一成系统
- [ ] 转场时长合适、不遮关键画面
- [ ] 换字卡的文案准确无误
