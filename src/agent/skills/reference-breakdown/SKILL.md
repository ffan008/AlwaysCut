# 拆解参考片并复刻

用户给了参考片、要「照它剪」「复刻这条」时走本流程。目标是先**取证**拿到能作数的证据，再**读**懂它为什么成立，最后把结论写进项目文档，供后续照它排时间线。

## 第一步：取证（只收集，不解读）

证据要齐三种，且**词级优先**——画面事件挂在词上，切点落在哪个词比落在第几秒重要。

1. `read_transcript` 拿**词级文字稿**（含词级时间对齐）。没有语音的纯画面参考片则跳过此步，改以帧为准。
2. 找**切点**：用 `read_transcript` 的词时间、或 `detect_scenes` 检测场景边界，把镜头切点定位到词/帧。
3. 抽**带词标签的帧网格**：`view_asset_frames`（源素材）或 `view_timeline_frames`（已上时间线的片），按切点抽代表性帧，每帧挂上对应的词或时间标签。

## 第二步：读它（从证据到结论）

把文字稿和帧网格放在一起读，问三件事：

- 它靠什么留住人（钩子、payoff、节奏）？
- 论证/叙事怎么推进（镜头顺序、转场系统、信息密度）？
- **命门**是什么（改了就不是它）？哪些是可以重新设计的？

解读时**证据与解读分开写**：看到的写「看到」（哪一帧、哪段词），推断的写「推断」，没看清的写「未看清」，不要把猜测写成事实。

## 第三步：写进项目文档（write_project_doc）

用 `write_project_doc` 写六份，一份一职。参考真相与目标真相分开，一条参考可喂多条成片：

| 文档 | 写什么 | 属于 |
|---|---|---|
| `analysis` | 参考片整体为什么成立、命门、可重新设计处 | 参考真相 |
| `timeline` | 参考片按时间的对象清单：每条标证据粗细、对观众起什么作用、落在哪两个词之间 | 参考真相 |
| `objects` | 对象 → 元素/素材映射 + 每个对象的状态序列（入场→持续→变化→退出） | 参考真相 |
| `brief` | 用户的目标、受众、硬约束、他保留的决定（目标真相） | 目标真相 |
| `treatment` | 你的创作答案：从钩子到 payoff 怎么走、和参考片哪里不同 | 目标真相 |
| `progress` | 当下快照：进行到哪、下一步、真实阻碍 | 目标真相 |

## 注意事项

- **重写不是追加**：同名覆盖，文档永远是「现在的真相」，过时结论删掉。
- **多参考片**：参考文档带后缀 `analysis-<slug>`、`timeline-<slug>`、`objects-<slug>`，互不覆盖。
- `treatment` 定下来之前不动时间线；复刻时以 `objects` 的状态序列为准排时间线，不是按镜头堆。
- 未看清的证据宁可不写，不要为了「完整」编一个数值或帧。
