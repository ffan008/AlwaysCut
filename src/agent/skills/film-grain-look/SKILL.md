# 胶片复古质感

当用户说「胶片感 / 复古 / 老视频 / 日系 / 怀旧 / 有颗粒感」时使用本技能。核心是给画面套上胶片基调，再叠加颗粒（grain）和褪色（fade），让数字感降低、有老胶片的温度。

## 什么场景用

- 生活记录、旅行、街拍想有复古胶片味
- 用户抱怨画面「太数码、太干净、没有质感」
- 想做出日系、昭和、90 年代家庭录像的观感

## 步骤

1. **先测数值**：调用 `inspect_color` 看当前帧的饱和度、黑白点与色相直方图，确定褪色起点。
2. **分析现状**：调用 `auto_grade`（mode 为 `analyze`）读取现有滤镜，避免重复叠加。
3. **套胶片基调**：调用 `auto_grade`（mode 为 `apply`）落地胶片 film-look 调色（内部走 `setFilters`）——整体压对比、轻提暗部、把黑位抬成灰，营造褪色感。
4. **加颗粒与褪色**：调用 `manage_effects` 给片段加胶片颗粒（grain）和褪色（fade）效果，颗粒强度按画面分辨率与内容调整。
5. **预览回看**：调用 `view_timeline_frames` 在关键帧确认颗粒不糊脸、褪色方向统一、暗部没有发灰到失焦。

## 注意事项

- 颗粒宁可偏轻也不要重到像噪点；人脸、文字区域颗粒过重会破坏可读性。
- 褪色不等于发灰发暗：黑位抬高要有度，`inspect_color` 报的黑点过灰就要回拉。
- 日系倾向低饱和、偏青偏暖；老视频倾向偏黄褐、加轻微划痕感，按用户原话选方向。
- 只处理用户指定的片段或整轨，不要顺带改动其它素材。

## 交付前自检

- [ ] `inspect_color` 已看过数值，褪色方向符合「胶片/复古/日系」而非发灰
- [ ] `auto_grade` 已 apply 且未重复叠加同类滤镜
- [ ] 颗粒与褪色已加，主体与人脸清晰可辨
- [ ] `view_timeline_frames` 已确认关键帧观感统一
