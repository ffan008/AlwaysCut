# 片尾关注引导卡（End Card CTA）

## 适用场景

用户要「加个片尾 / 结尾卡 / 关注引导」时，在正片末尾加一张关注引导卡：色块铺底 + 主副文案 + 同步淡出。

## 工作流

1. 铺底色块：用 `edit_item` 在片尾放全屏色块铺底。
2. 放主文案：用 `edit_item` 放置主文案（关注 / 点赞 / 订阅等核心引导）。
3. 放副文案：用 `edit_item` 放副文案（下一集预告、账号名、补充说明）。
4. 控制时长：用 `set_item_timing` 给片尾卡留足阅读时间。
5. 同步淡出：让片尾卡与画面 / 音频同步淡出。

## 注意事项

- 主副文案层级分明：主文案最大最醒目，副文案弱一级。
- 片尾卡文字不要与正片字幕打架。
- 片尾卡时长足够读完主文案，但不要拖太长。

## 交付前自检

- 片尾卡文字清晰、层级分明。
- 时长合适，淡出自然。
- 引导目标（关注 / 点赞 / 订阅）明确。
