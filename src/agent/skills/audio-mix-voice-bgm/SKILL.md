# 人声 + BGM 分层混音

当用户说「BGM 太吵 / 配乐盖住人声 / 背景音乐压过说话 / 音乐和人声打架」时使用本技能。核心是以人声为基准，先归一响度，再按讲话段落把 BGM 压低（ducking），让 BGM 在说话时让位、在空档时补回。

## 什么场景用

- 口播、访谈、解说、vlog 中 BGM 与人声同时存在但互相干扰
- 用户要求「人声大一点、音乐小一点」且希望自动随说话段起伏
- 需要分层混音，让说话清晰、音乐不断气

## 步骤

1. **盘清音频**：调用 `list_audio` 列出时间线上的所有音轨，区分人声轨与 BGM 轨（配乐可先走已有 `music` 技能生成，或在素材库挑选）。
2. **定位讲话段**：调用 `read_transcript` 拿人声的讲话时间区间，作为 BGM 让位的依据；若无转写可用，再考虑 `detect_beats` 或 `inspect_music` 辅助定位。
3. **响度归一**：调用 `normalize_loudness` 对人声轨和 BGM 轨分别归一，先让各自基准响度一致，避免后续 ducking 忽高忽低。
4. **按段让位**：调用 `edit_item` 在讲话段给 BGM 加音量包络/关键帧，压低约 6–12 dB，在句间空档恢复，过渡用短渐变避免「咔」的跳动。
5. **回听自检**：调用 `verify_export` 或 `view_timeline_frames` 回听关键交接点，确认人声清晰、BGM 起伏自然。

## 注意事项

- 人声是基准：先保证人声清晰可懂，BGM 只是衬底，不要反向把 BGM 抬到盖人声。
- ducking 的压幅与过渡时长要顺滑，段落边界不能有音量跳变。
- 不要对整段 BGM 一刀切压低，只在有讲话的区间让位。
- 只在用户要求混音时才动音量，不擅自改素材或变速。

## 交付前自检

- [ ] `list_audio` 已确认人声轨与 BGM 轨
- [ ] `read_transcript` 已拿到讲话段，让位区间正确
- [ ] `normalize_loudness` 已归一，基准响度一致
- [ ] `edit_item` 已按段 ducking，回听交接点自然
- [ ] 人声清晰、BGM 起伏顺滑、无音量跳变
