# 音频降噪修复

当用户说「有杂音 / 底噪 / 电流声 / 风噪 / 声音糊 / 有爆音」时使用本技能。核心是先定位噪声类型与位置，再用 AI 降噪（人声分离/降噪）或剪辑手段修复，尽量保留有用的说话或环境声。

## 什么场景用

- 口播、访谈、现场录音里混入底噪、电流声、风噪、空调声
- 用户反馈「背景嗡嗡响、有咔哒/爆音、人声被噪声盖住」
- 需要先判断哪段能修、哪段只能剪掉

## 步骤

1. **盘清音频**：调用 `list_audio` 列出时间线上的音频片段，标记可疑噪声段。
2. **定位噪声**：逐段回听或结合 `read_transcript` 判断噪声是持续底噪、偶发爆音还是风噪，确定「降噪」还是「剪辑」。
3. **AI 降噪**：对持续底噪/风噪段调用 `isolate_voice` 做人声分离/降噪，保留清晰人声、抑制背景噪声。
4. **剪辑修复爆音**：对偶发爆音/咔哒，调用 `edit_item` 修剪或用音量包络压掉尖峰；无法救回的段直接切除并波纹闭合。
5. **响度归一**：修复后调用 `normalize_loudness` 让整段响度一致，避免降噪段忽大忽小。
6. **回听自检**：调用 `view_timeline_frames` 或 `verify_export` 回听修复段，确认噪声已降、人声仍自然。

## 注意事项

- 先定位再动手：持续噪声走 `isolate_voice` 降噪，偶发爆音走 `edit_item` 剪辑，别用错手段。
- 降噪有代价：过度分离会把人声也「抽干」或产生水声/金属感，宁留一点底噪也别过度处理。
- 爆音切除要波纹闭合、加短淡入淡出，避免切口处再产生咔哒。
- 只处理用户指定的音频段，不擅自改 BGM 或无关音轨。

## 交付前自检

- [ ] `list_audio` 已列出并标记噪声段
- [ ] 持续噪声已走 `isolate_voice`，偶发爆音已走 `edit_item`
- [ ] `normalize_loudness` 已归一，响度一致
- [ ] 回听确认噪声已降、人声自然无抽干感
