# 双人播客成片（Two Person Podcast）

## 适用场景

把双人播客 / 对谈素材剪成成片：先定说话人身份，按「谁在说、给谁说」切换画面，对齐两人音量，分段组织内容，并给两人的字幕上不同颜色。

## 工作流

1. 定身份：调用 `read_transcript` 确认两人的说话人归属；归属错乱时用 `manage_transcript` 的 `fix` 修正 speaker 标签。
2. 切画面：按「说话者优先」原则，用 `split_item` 分段，再用 `edit_item` / `move_item` 组织成「说话人镜头为主、必要时给听者反应镜头」的切换。
3. 对音量：用 `normalize_loudness` 对齐两人的响度，让切换时不忽大忽小。
4. 分段组织：用 `read_script` 通读、整理出清晰的段落结构，再用 `apply_script` 落回时间线；口误停顿可用 `clean_script` 清理。
5. 分色字幕：用 `edit_captions` 给两人的字幕分别上不同颜色，一眼区分谁在说话。

## 注意事项

- 先定谁是谁，再切画面，避免张冠李戴。
- 切画面遵循「说话者优先」，听者反应镜头只在有信息量时给。
- 不要为了切换而频繁切，破坏听感。

## 交付前自检

- 用 `read_captions` 确认两人字幕颜色区分清楚。
- `normalize_loudness` 后两人音量接近，无忽大忽小。
- 分段结构清晰，画面切换与内容节奏一致。
