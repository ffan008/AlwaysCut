# 重点词台阶推近强调（Punch Zoom Emphasis）

## 适用场景

口播或解说里某个关键词、金句、结论需要被强调，用「逐级推近放大 + 短震」把观众的注意力钉在重点上。常见于短视频金句、数据揭晓、情绪爆发点。

## 工作流

1. **定位重点词**：调用 `read_transcript` 拿到词级时间，锁定要强调的词或短语的起止帧。
2. **看构图**：用 `view_timeline_frames` 确认该帧画面，确保推近后不裁掉人脸或关键信息。
3. **逐级推近**：用 `edit_item` 给该镜头设 scale 关键帧——从 100% 分 2–3 级推近到目标（如 110%→125%→140%），每级落在重音上；或用 `add_motion_graphic` 套「文字台阶推近」母版做大字强调。
4. **加短震**：在最高级停留的那 2–4 帧，用 `edit_item` 加微小的位置抖动（短震），强化冲击，随后回稳。
5. **配重音**：必要时用 `add_audio` 在推近顶点补一个 riser 或重音 hit，让画面和声音一起「砸」下来。

## 注意事项

- 台阶推近要跟词重音对齐，别做成匀速缩放（那会像卡顿）。
- 短震幅度要小（几个像素）、次数少，避免画面发抖、观众不适。
- 一次只强调一个重点，别整段都推近，会失去「重点」的意义。
- 推近后画面必须仍可读，用 `place_graphics_in_safe_zone` 或手动确认不遮挡。

## 交付前自检

- [ ] 重点词已通过 `read_transcript` 锁定精确帧
- [ ] 推近分 2–3 级、每级落在重音上
- [ ] 短震幅度小、次数少，不发抖
- [ ] 推近顶点画面可读、不遮挡人脸/字幕
