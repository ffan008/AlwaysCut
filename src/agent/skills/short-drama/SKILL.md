# 短剧剪辑（Short Drama）

## 适用场景

把带对白的剧情素材剪成短剧：开场 3 秒抛钩子，按情绪节拍换画面，多角色字幕一眼分清，结尾回收钩子。

## 工作流

1. 理剧情：用 `read_transcript` 理清人物关系、剧情走向和情绪节拍。
2. 开场抛钩子：把冲突 / 反转 / 悬念提前到前 3 秒，用 `split_item` / `move_item` 重组。
3. 按情绪节拍换画面：用 `detect_scenes` 找切点，`edit_item` 按情绪节拍切换镜头；情绪高点放大。
4. 分角色字幕：用 `edit_captions` 给不同角色字幕上不同颜色，一眼分清谁在说。
5. 结尾回收：用 `read_script` + `apply_script` 让结尾回收开头的钩子。

## 注意事项

- 每场戏只保留推进剧情的对白，删掉与主线无关的闲聊。
- 情绪节拍是换画面的依据，不要机械地平均切。
- 开场钩子要制造「接下来会怎样」的悬念。

## 交付前自检

- 开场 3 秒有钩子，能让人想知道后续。
- 画面切换与情绪节拍一致。
- 多角色字幕颜色区分清楚。
- 结尾回收了开头的钩子。
