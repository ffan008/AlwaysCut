# 旁白主导演示片

这类片以**旁白为主线**，画面是给旁白配的演示/操作。核心顺序：先把话写顺 → 给每句配可见动作 → 录屏按旁白切开 → 配音对时 → 上整句字幕。

## 步骤

1. **写旁白**：先写顺要说的话，按目标时长分段（每段一句或一个完整意思）。写的过程中同步决定每句配什么**可见动作**——画面事件挂在词上，哪句该出现哪一步操作、哪个界面，先想清楚再动时间线。
2. **录屏切开**：有录屏素材时，`read_transcript` 拿词级时间，按旁白句在对应词处 `split_item` 切开，再用 `edit_item` 把片段对齐到每句旁白。
3. **配音**：需要 AI 配音时 `submit_voice`，`track_progress` 查任务；用真实配音的，直接以其词级时间为准。
4. **对时**：用**实测词时间**把配音与画面对齐，不靠估——换词换配音后重新用词时间对位。
5. **整句字幕**：`read_captions` 核对字幕按整句断句、与配音钉在同一段词上。

## 注意事项

- **先话后画**：话没写顺不排画面，否则改一句全片重排。
- **切点落在词上**，不落在第几秒；停顿和词是比秒更可靠的锚。
- 每句旁白必须配一个**看得见的动作**，没有画面支撑的句子要补演示/操作，或删掉。
- 配音、字幕、画面三者对齐以最终配音的词级时间为唯一基准。
