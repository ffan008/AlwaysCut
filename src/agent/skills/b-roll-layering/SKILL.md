# 口播配补充画面（B-roll 铺覆盖轨）

口播为主、需要补充画面把「说的话」可视化时走本流程。关键不是「随便塞点画面」，而是先判断**观众此刻需要看什么**，再铺上去，最后逐条核对。

## 步骤

1. **读口播，判断观众需要看什么**：`read_script` 或 `read_transcript` 读内容，逐段判断——这段讲的是概念、产品、场景还是步骤？观众此刻最需要看到什么才能跟上？把结论挂到对应的词上。
2. **找素材**（按优先级）：
   - 已有素材：`manage_media_pool` 查项目里现成的，`view_asset_frames` 看内容是否匹配。
   - 在线素材：`search_stock_media` 找合适的空镜/演示。
   - 生成：都没有时才 `submit_image` / `submit_video` 生成，`track_progress` 跟进。
3. **铺到覆盖轨**：用 `edit_item` 把选好的画面放到覆盖轨，对齐到对应那句口播的词区间——切点落在词上，别落在第几秒。
4. **逐条核对**：`view_timeline_frames` 抽每段补充画面的帧，确认「画面支持口播」而不是抢戏、遮挡字幕或主体。

## 注意事项

- **先判断需要，再找素材**：观众需要的画面决定找什么，别先囤一堆素材再硬配。
- **覆盖轨不挡主体与字幕**：补充画面位置避开人脸、字幕、关键信息区；挡不住就换素材或改成短切。
- **别过度铺**：没补充价值的段落（如情绪铺垫）可以不铺，留口播自己说；B-roll 是可选增强，不是每句都要盖。
- 每条铺完都回读确认（`view_timeline_frames` / `read_script` 回读），素材在库里不等于上了时间线。
