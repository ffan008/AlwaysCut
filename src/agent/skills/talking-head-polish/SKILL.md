# 口播删改判据（Talking Head Polish）

## 适用场景

用户口播录了多遍，或一段话里有口误、口头禅、卡壳、重复，需要判断「留哪条、删哪条、口误怎么补」，让成片顺、自然、不留破绽。

## 判据（优先级从高到低）

1. **语义完整**：一句话被切断也要保证意思不残缺；宁留稍长的完整句，不硬凑短句。
2. **无口误无卡壳**：读错、咬字不清、明显卡顿的 take 优先淘汰。
3. **语气自然**：不生硬、不赶、情绪和上下文一致；重录段落里挑最自然的那遍。
4. **与前后连贯**：声调、语速、音量不突兀，接得上上一句和下一句。
5. **时长合适**：在不违背前四条的前提下，选节奏更紧凑的那条。

## 工作流

1. **定位重录/口误**：调用 `read_transcript` 拿词级转写，找出重复句、口误词、卡顿词，标出「说了几遍」的段落。
2. **逐段取舍**：对每个重录段，按上面判据选最优 take，其余用 `remove_item` 删除；记录取舍理由（在 `progress` 里写一句即可，不必逐条）。
3. **补口误**：口误词可调用 `edit_captions` 直接改字幕，但若「听感」也会错，需 `edit_item` 剪掉该词或用干净 take 替换，不要只改字幕不改声。
4. **收紧衔接**：用 `edit_gap` 收紧删段后的空隙，加短交叉淡化或淡入淡出，避免切口处出现咔哒或跳音。
5. **重钉字幕**：切完后用 `edit_captions` / `read_captions` 让字幕跟新的词时间对齐。

## 注意事项

- 先定判据再动手：不要按「先录后录」机械取舍，要按语义和自然度。
- 只删不改原话：不要擅自改写用户原意，除非用户明确要精简。
- 切口处要听一遍：删词后相邻两字可能连成怪音，用 `view_timeline_frames` 回听确认。
- 用 `undo_last_change` 回退取舍错的段落。

## 交付前自检

- [ ] `read_transcript` 已定位全部重录/口误段
- [ ] 每段都按判据保留了最优 take，删除了其余
- [ ] 切口处已用 `edit_gap` 收紧并回听无咔哒
- [ ] 字幕已跟新时间对齐，不残留错词
