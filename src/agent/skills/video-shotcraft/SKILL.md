# 电影感产品宣传片（Video Shotcraft）

## 适用场景

给产品/品牌做一条有电影感的宣传片：不是平铺直叙的功能罗列，而是用镜头的景别、运动、光影、节奏讲出「质感」和「情绪」。适用于新品发布、品牌形象片、高端产品广告。

## 镜头卡库（157 镜头，按功能取用）

| 镜头类别 | 作用 | 取用时机 |
|---|---|---|
| 开场钩子 | 3 秒内抓住注意力 | 片头第一镜 |
| 产品特写 | 细节、材质、工艺 | 卖点讲解时 |
| 氛围镜头 | 场景、光影、留白 | 情绪铺垫、转场呼吸 |
| 卖点镜头 | 功能演示、对比 | 论证卖点时 |
| 人物镜头 | 使用场景、代入感 | 讲体验/情感时 |
| 收尾落版 | logo + CTA | 片尾 |

先用 `read_project_doc` 读 brief/treatment，明确「这条片要传达的一个核心信息」和「目标人群」，再据此从镜头卡库里选镜头，不要先拍后想。

## 工作流

1. **定调子**：读 brief，确定情绪基调（高级/科技/温暖/年轻），写进 treatment。
2. **拉参考**：有参考片走 `storyboard-shot-breakdown` 拆解；没有就直接用镜头卡库规划分镜。
3. **选镜头**：用 `view_asset_frames` 看素材，按镜头卡库功能给每个分镜位选镜头，标注景别/运动/时长。
4. **排时间线**：用 `edit_item` 按分镜排镜头，控制节奏（钩子快、卖点稳、落版慢）。
5. **调色**：用 `inspect_color` + `auto_grade` 统一电影感色调，全片一个影调。
6. **配乐与声**：`submit_music` 配乐、`submit_voice` 配音，`normalize_loudness` 统一响度。

## 注意事项

- 镜头要「为卖点服务」：每个镜头对应一个信息或情绪，删掉无意义的空镜。
- 景别要变化：特写/中景/全景交替，别一路怼特写。
- 全片影调统一，别每个镜头各调各的。
- 落版 logo 用 `add_motion_graphic` 套落版母版，CTA 清晰。

## 交付前自检

- [ ] 核心信息已写进 treatment，镜头卡库选镜完成
- [ ] 镜头有景别变化、节奏有张弛
- [ ] 调色统一、配乐/配音到位、响度一致
- [ ] `verify_export` 五项质检通过
