# 数据条形竞赛（Data Bar Race）

## 触发场景
- 「把这组数据做成动态图表」「销量对比做个动画」
- 「投票结果可视化」「评分排行做成动效」
- 「年度数据盘点的一段动画」

## 何时不用
- 单个数字强调 → 用「大字动效片头」的数字幕
- 静态表格能说清且时长紧 → 不必动效化
- 需要多轮"你追我赶"换位的真竞赛 → 本母版是一次排序定格型，不换位

## 使用流程
1. `add_motion_graphic({ templateName: "数据条形竞赛" })` 放置母版（默认 CONFIG 已含示例数据）
2. `update_item_props({ itemId, props: { title, unit, itemsJson, bg, ink, accent, bar, muted } })` 改数据与配色
3. 渲染抽「生长中 / 定格后」两帧核对数字与标签；播放检查节奏

## 可改 props（改这些即得成品）
- `title` 标题 · `unit` 单位
- `itemsJson`：JSON 字符串数组，形如 `[{"label":"耶加雪菲","value":1280},{"label":"瑰夏","value":960}]`，**按值降序填**（母版不做排序插值，顺序即最终排名）
- `bg` 背景 · `ink` 主字 · `accent` 强调色（只用于第一名条+单位）· `bar` 条形灰 · `muted` 弱字

## 硬规矩
- 数据必须来自真实来源（工程统计/用户给的表），**禁止编造数字**；数据没有就问用户要
- 强调色一屏至多 2 处（第一名条 + 单位标签）

## 验收
- 条形最终长度与数值比例一致（肉眼核最大/最小值）
- 定格帧数字滚动已结束，显示目标值
- accent 只出现在第一名相关元素
