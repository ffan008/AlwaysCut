# 照片缓慢推近横移（Ken Burns Motion）

## 适用场景

静态照片、截图、封面图放进视频时，直接硬放会呆板。用缓慢的推近、拉远或横移让画面「活」起来，是相册、回忆视频、产品图展示的基础手法。

## 工作流

1. **看构图定方向**：用 `view_asset_frames` 看每张照片，判断视觉重心在哪，据此选运动方向——重点在中心→缓慢推近；想交代环境→拉远；横向构图→横移；想带叙事→对角线移动。
2. **设关键帧**：用 `edit_item` 给照片设 scale/position 的起止关键帧，起点和终点之间做匀速或缓动（缓动更自然，起慢止慢）。
3. **控时长幅度**：单张照片 2–4s，推近幅度 105%–120% 左右；幅度别太大、速度别太快，否则像缩放演示而非电影感。
4. **接力转场**：多张照片之间用叠化或滑动衔接，配合 `sync_images_to_music` 让切换卡在节拍上。
5. **回看**：用 `view_timeline_frames` 确认动势顺滑、无跳变、重心不跑偏。

## 注意事项

- 方向要服务内容：推近=聚焦细节，拉远=交代全景，横移=横向叙事，别随机选。
- 匀速死板，缓动自然：起止点设 ease-in/out。
- 幅度克制：默认 105%–120%，避免「怼脸」或画面发糊（放大过多会露像素）。
- 每张照片方向可以不同，但同一条片子里要成节奏，别忽快忽慢。

## 交付前自检

- [ ] 每张照片都定了明确的运动方向（推/拉/移）
- [ ] 关键帧用了缓动，无匀速缩放感
- [ ] 幅度 105%–120%、时长 2–4s，无糊脸/露像素
- [ ] 多张切换卡在节拍、转场统一
