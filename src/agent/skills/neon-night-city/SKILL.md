# 夜景霓虹光晕

当用户说「夜景 / 霓虹 / 赛博朋克 / 灯光更亮 / 城市夜景 / 未来感」时使用本技能。核心是提亮夜景灯光、拉高色彩饱和，再给高光加霓虹光晕（glow），营造赛博都市感。

## 什么场景用

- 城市夜景、灯牌、车流、霓虹街道素材
- 用户觉得「灯光太暗、颜色不跳、没有赛博朋克味」
- 想把普通夜景做成高饱和霓虹风格

## 步骤

1. **先测数值**：调用 `inspect_color` 看当前帧的黑白点、溢出比例与高光饱和，确定提亮与加饱和的余地。
2. **分析现状**：调用 `auto_grade`（mode 为 `analyze`）读取现有滤镜。
3. **提亮灯光 + 拉饱和**：调用 `auto_grade`（mode 为 `apply`）落地夜景技术调色（内部走 `setFilters`）——提亮高光与霓虹色相、适度压暗死黑、拉高整体饱和，突出霓虹色彩。
4. **加霓虹光晕**：调用 `manage_effects` 给片段加高光 glow 光晕，让霓虹灯牌有发光感。
5. **预览回看**：调用 `view_timeline_frames` 在关键帧确认霓虹不溢出成纯色、暗部不发灰、光晕不糊主体。

## 注意事项

- 高饱和容易溢出：`inspect_color` 报的溢出比例超阈值就回调饱和，别让霓虹糊成一团纯色。
- 提亮灯光别把天空/暗部也一起提灰，暗部保持干净的黑。
- 光晕强度适中，灯牌要发亮但边缘别虚化过度。
- 只处理用户指定的片段或整轨。

## 交付前自检

- [ ] `inspect_color` 已看过数值，霓虹色相突出、无明显溢出
- [ ] `auto_grade` 已 apply 且未重复叠加同类滤镜
- [ ] 灯光已提亮、饱和已拉高、光晕已加
- [ ] `view_timeline_frames` 已确认关键帧赛博氛围到位
