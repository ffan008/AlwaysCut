# 排行榜 / 盘点视频（Ranking Listicle）

## 适用场景

排行榜、TOP10、榜单、盘点类视频：开场先给一个「已知名次」做悬念，逐条用证据揭晓并给出判断。

## 工作流

1. 提取素材：用 `read_transcript` 提取每条排名、上榜理由和证据。
2. 开场定名次：开场先亮出观众已知的某个名次 / 悬念，制造期待。
3. 逐条揭晓：用 `read_script` + `apply_script` 按排名顺序组织，每条先揭晓再给证据；用 `edit_item` 放证据画面 / 文字卡。
4. 给判断：每条配一句点评 / 判断，让榜单有观点。
5. 配节奏：可选 `detect_beats` + `sync_cuts_to_music` 让揭晓节奏更有律动。

## 注意事项

- 每条必须有证据支撑，不能只报名字。
- 名次揭晓要有节奏感和停顿，制造「下一条是谁」的期待。
- 观点判断要有依据，不凭空贬低或吹捧。

## 交付前自检

- 开场有悬念（已知名次或冲突）。
- 每条都有证据画面 / 文字，揭晓顺序正确。
- 判断 / 点评到位。
