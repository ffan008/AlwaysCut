# 清晰明亮教程风

当用户说「画面发灰 / 太暗 / 教学要清楚 / 录课看不清 / 画面不通透」时使用本技能。核心是修正发灰发暗的画面，提亮、去灰、加对比和清晰度，让教学内容（人脸、板书、屏幕、字幕）一目了然。

## 什么场景用

- 课程、教程、口播、录屏、产品演示画面偏暗偏灰
- 用户要求「画面清楚一点、亮一点、通透一点」
- 需要信息优先、减少氛围滤镜干扰的功能性画面

## 步骤

1. **先测数值**：调用 `inspect_color` 看当前帧的黑白点与饱和度，判断发灰/偏暗的具体位置。
2. **分析现状**：调用 `auto_grade`（mode 为 `analyze`）读取现有滤镜。
3. **提亮去灰**：调用 `auto_grade`（mode 为 `apply`）落地技术调色（内部走 `setFilters`）——抬黑白点、加对比、轻提饱和与清晰度，去掉灰蒙感，不引入偏色。
4. **可选去静音**：教学视频若有大量死气段，调用 `remove_silence`（必要时先开 dryRun 预览）收紧节奏，但不切音乐床。
5. **预览回看**：调用 `view_timeline_frames` 在关键帧确认文字、人脸、屏幕内容清晰，无过曝、无偏色。

## 注意事项

- 以「清楚」优先，不要套青橙、颗粒等氛围滤镜，避免干扰教学信息。
- 提亮有度：白板/屏幕别过曝到看不清，`inspect_color` 报溢出就回调。
- 肤色要自然，去灰不是去饱和到蜡黄。
- 只处理用户指定的片段或整轨，去静音前先确认不会误切有效内容。

## 交付前自检

- [ ] `inspect_color` 已看过数值，黑白点正常、无明显溢出
- [ ] `auto_grade` 已 apply，画面变亮变清、无偏色
- [ ] 文字、人脸、屏幕内容清晰可读
- [ ] `view_timeline_frames` 已确认关键帧通透
