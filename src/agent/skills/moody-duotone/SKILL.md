# 双色调情绪片

当用户说「情绪片 / 氛围感 / ins 风 / 双色调 / 蓝调 / 暗调」时使用本技能。核心是压暗整体、把画面收敛到两种主色（双色调），再点缀光斑，营造克制的情绪氛围。

## 什么场景用

- 人像、静物、街景想有安静的情绪氛围
- 用户觉得画面「太亮、太吵、没氛围、想统一成某个色调」
- 想做 ins 风、小红书风格的统一双色视觉

## 步骤

1. **先测数值**：调用 `inspect_color` 看当前帧的黑白点、饱和度与色相直方图，确定压暗与双色的起点。
2. **分析现状**：调用 `auto_grade`（mode 为 `analyze`）读取现有滤镜。
3. **压暗 + 双色调**：调用 `auto_grade`（mode 为 `apply`）落地双色调技术调色（内部走 `setFilters`）——压暗中间调与高光，把画面收敛到两个主色（如深蓝 + 暖棕），去掉杂色。
4. **加光斑**：调用 `manage_effects` 给片段加光斑/光晕效果，光斑位置与强度以「增加氛围、不盖主体」为准。
5. **预览回看**：调用 `view_timeline_frames` 在关键帧确认双色统一、压暗不过度、光斑自然。

## 注意事项

- 双色调要干净：杂色会破坏情绪，`inspect_color` 里饱和度与色相分布太散就先收敛。
- 压暗别把主体压成剪影，除非用户明确要剪影；人脸保留可辨识度。
- 光斑是点缀不是主角，数量与亮度宁少勿多。
- 只处理用户指定的片段或整轨。

## 交付前自检

- [ ] `inspect_color` 已看过数值，双色收敛、无明显杂色
- [ ] `auto_grade` 已 apply 且未重复叠加同类滤镜
- [ ] 压暗与光斑已加，主体仍清晰
- [ ] `view_timeline_frames` 已确认关键帧氛围统一
