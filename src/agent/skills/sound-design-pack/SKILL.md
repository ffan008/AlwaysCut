# 四层音效铺排

当用户说「加点音效 / 没氛围 / 声音单薄 / 太干了 / 想要转场音效」时使用本技能。核心是按转场、强调、UI、氛围四层分层铺音效，让声音有层次、不单薄，同时不盖住人声和 BGM。

## 什么场景用

- 短视频、vlog、产品演示、游戏剪辑需要节奏与氛围
- 用户觉得画面转场生硬、缺少「爽点」或氛围音
- 需要在卡点处同步铺音效

## 步骤

1. **盘点现有音频**：调用 `list_audio` 看当前人声与 BGM 占用情况，确认铺音效的余量，避免叠爆。
2. **选音效**：调用 `browse_library`（音效库）按四层找素材——转场 whoosh/riser、强调 hit/boom、UI 提示音、氛围 ambient。找不到合适的再考虑已有 `voice` 技能生成自定义音效。
3. **定位卡点**：若音效需卡节奏，调用 `detect_beats` 或 `inspect_music` 拿节拍/段落，必要时用 `music_edit_plan` 规划落点。
4. **铺音效**：调用 `add_audio`（或 `edit_item`）把音效放到对应时间点——转场压在镜头切换处、强调压在动作/台词重点、UI 压在信息出现处、氛围铺满整段。
5. **卡点对齐**：若音效要随音乐卡点，调用 `sync_cuts_to_music` 对齐节奏，确保音效落点与节拍吻合。
6. **回听自检**：调用 `view_timeline_frames` 或 `verify_export` 回听，确认四层平衡、无爆音、不盖人声。

## 注意事项

- 音效是点缀，宁少勿多：四层不必每层都铺满，转场和强调优先，UI 和氛围按需。
- 每层响度要有主次，`normalize_loudness` 可用于统一，但别让音效压过人声。
- 先 `browse_library` 找现成素材，找不到了再生成自定义音效，不要默认生成。
- 卡点要准，落点错了会显业余。

## 交付前自检

- [ ] `list_audio` 已确认叠音效的响度余量
- [ ] `browse_library` 已按四层选好音效（找不到才生成）
- [ ] `detect_beats`/`inspect_music` 已定位卡点
- [ ] 音效已用 `add_audio`/`edit_item` 铺到正确位置，必要时已 `sync_cuts_to_music`
- [ ] 回听四层平衡、无爆音、不盖人声
