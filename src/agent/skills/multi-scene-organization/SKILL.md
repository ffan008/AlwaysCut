# 长项目与多成片的组织

一条片子很长、或一个工程要出多条成片时，混乱来自没有统一的场景边界、轨道分层和命名。本技能给出组织规范。

## 步骤

1. **场景划分**：用 `detect_scenes` 找场景/段落边界，或 `read_transcript` 按话题段落切分。划分标准是「观众视角的一段完整信息」，不是纯技术切点。
2. **打标记**：`manage_markers` 给每个场景/段落打标记，命名稳定、可读，作为后续定位锚点。
3. **轨道分层**：一条轨道只放一类对象（口播 A-roll / B-roll / 字幕 / 音乐 / 音效 / 图形），用 `edit_item` 把素材归到对应轨道；同类内容散在多条轨道时先归位，再删空轨道。
4. **多成片用版本管理**：一个工程出多条成片（少儿版、竖屏版、英文版）时用 `manage_versions` 建版本，目标文档用后缀变体（`brief-<slug>`、`treatment-<slug>`）区分，不覆盖原版。
5. **统一视觉**：跨场景/跨成片用 `manage_design_style` 统一视觉语言，让不同段落在同一家族里。

## 命名与分层规范

- 轨道命名短且表意：`VO`、`B-roll`、`字幕`、`Music`、`SFX`；一个角色一条轨，别让「说话」散在两条轨上。
- 对象随时间变化的多个状态（同一个转场系统出现十次）是**一个对象的十个状态**，不是十个独立对象——命名按对象走，不按出现次数走。
- 版本命名带语义（`少儿版`、`16:9`），不用 `v2`、`final` 这类无信息名。

## 注意事项

- 先读现有布局再动：`read_project_doc`（`progress`）和 `read_script` 看当前轨道与段落，别重复建轨。
- 改动在它所属的地方改，别绕过去打补丁；中途建的空轨道、占位元素在停手前删掉。
- 画布是全项目共享的，另一画幅要先 `auto_reframe` 或切场景后按新画幅重排。
