# 删停顿收紧节奏（Silence Tighten）

## 适用场景

口播、访谈、课程里出现长停顿、冷场、频繁的「呃 / 嗯」之后的空拍，让节奏拖沓。目标是删掉多余静音、保留正常呼吸和语感，成片更紧凑但不过度。

## 工作流

1. **盘音轨与静音**：调用 `list_audio` 看音轨，`detect_scenes` 或 `read_transcript` 定位静音/停顿段，标出时长异常的冷场。
2. **设定阈值**：正常呼吸停顿约 0.2–0.5s，超过 0.8–1.2s 的长停顿才删；不要一刀切，避免把语速压成「机关枪」。
3. **删长停顿**：调用 `remove_silence` 批量删除超标停顿；对局部长冷场用 `edit_gap` 手工收紧。
4. **微调切点**：每个删减切口用 `edit_gap` 加 1–2 帧交叉淡化，避免切口处呼吸被切出「咔哒」或字头被吞。
5. **语义复核**：调用 `read_transcript` 确认删除没有切断语义、没有把两句话黏成一串。
6. **响度平滑**：删减后调用 `normalize_loudness` 让整体响度一致。

## 注意事项

- 阈值分场景：严肃演讲/访谈留多点呼吸，快节奏短视频压狠一点，别用同一参数。
- 保留句首/句尾的自然呼吸，只删「冷场级」长停，不删正常停顿。
- 删完后逐段回听，确认没有「喘不上气」的压迫感。
- 只处理用户指定的音轨，不擅自动 BGM。

## 交付前自检

- [ ] `list_audio` 已列出并标记长停顿/冷场段
- [ ] `remove_silence` 只删超标停顿，未切碎语义
- [ ] 每个切口已加短淡化并回听无咔哒
- [ ] `normalize_loudness` 已归一，响度一致
