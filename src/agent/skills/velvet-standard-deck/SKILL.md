# 天鹅绒宣言（Velvet Standard Deck）

## 触发场景
- 「品牌宣言一屏」「高端发布会开场」「章节过渡的仪式感页面」
- 奢侈品、企业软件、主题演讲的沉稳高级风格
- 一句话值得被慢慢读的时刻

## 何时不用
- 数据指标 → 用「瑞士数据脉冲」
- 高能量促销 → 用「最大化字体」
- 内容是「快」的气质（限时/秒杀/燃）→ 别用这个慢板

## 使用流程
1. `add_motion_graphic({ templateName: "天鹅绒宣言" })` 放置母版
2. `update_item_props({ itemId, props: { eyebrow, headline, sub, bg, ink, gold, muted } })` 改文案与配色
3. 渲染抽 1.5s / 5s 两帧核对居中与金线

## 可改 props
- `eyebrow` 顶部全大写小标 · `headline` 宣言大字（一行为佳）· `sub` 副题（斜体）
- `bg` 深底 · `ink` 主字 · `gold` 金线 · `muted` 弱字

## 设计规约（改模板时保持）
- 留白 ≥ 55%、全大写细字距小标（0.35em+）、金色只给细线与一两处字
- 节奏是慢板：边框果断划出（0.5s）后，大字缓落 + 字距收紧 → 上下金线对称展开 → 副题浮现 → 长定格
- 定格期只有背景径向暖光极缓呼吸（唯一环境动效）

## 验收
- 居中对称、金线划出、大字衬线从容
- 3s 后长定格、无多余动效
- 竖屏项目布局自适应（传 720×1280 也能用）
