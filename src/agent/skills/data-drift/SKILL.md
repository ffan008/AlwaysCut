# 数据漂移（Data Drift）

## 触发场景
- 「科技感标题页」「AI 产品发布」「机器学习/数据公司的指标页」
- 深空黑紫青 + 漂浮粒子 + 纤细未来感 + 数字凝聚的沉浸式科技画面

## 何时不用
- 临床精准的数据 → 用「瑞士数据脉冲」
- 高能量促销 → 用「最大化字体」
- 温暖人文 → 用「柔光时刻」

## 使用流程
1. `add_motion_graphic({ templateName: "数据漂移" })` 放置母版
2. `update_item_props({ itemId, props: { kicker, headline, metricLabel, metricValue, footnote, bg, ink, purple, cyan, muted, line } })` 改文案与配色
3. 渲染抽「指标凝聚中 / 定格后」两帧核对数字与文字

## 可改 props
- `kicker` 顶部小标 · `headline` 主标题 · `metricLabel` 指标标签 · `metricValue` 指标数字 · `footnote` 脚注
- `bg` 深空底 · `ink` 主字 · `purple` 紫 · `cyan` 青 · `muted` 弱字 · `line` 网格线

## 验收
- 粒子/网格确定性运动（无闪烁抖动），数字凝聚到位
- 文字纤细可读、不越界
- 深空黑紫青配色与 Pro 一致
