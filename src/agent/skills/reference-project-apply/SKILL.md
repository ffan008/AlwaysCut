# 参照工程应用

用户说「照上次那样剪」「跟旧版一样」「按那个模板来」时，不要凭印象重剪一遍——先读**参考文档**，再把结论套到当前工程。

## 步骤

1. **列清单**：`read_project_doc`（不带 name 参数）看现在有哪些文档。重点找参考真相三类：`analysis`、`timeline`、`objects`，以及它们的后缀变体 `analysis-<slug>`、`timeline-<slug>`、`objects-<slug>`。
2. **读参考**：`read_project_doc`（带 name）读对应的 `analysis-<slug>` / `timeline-<slug>` / `objects-<slug>`，弄清「那条片」为什么成立、对象怎么排、用了哪些元素。
3. **读目标**：读 `brief`（用户目标真相）和 `treatment`（创作答案），确认这一次要做什么、和参考片哪里该不同。
4. **套用**：按 `objects` 的状态序列排时间线，套用参考的转场系统、版式、节奏、配色。复用已有素材，不要因为「重新排」就重新生成。
5. **落地并核对**：用 `edit_item` 把对象/元素落位，`view_timeline_frames` 抽帧核对风格是否一致。

## 注意事项

- **参考真相与目标真相分开**：参考片说「它做了什么」，新片说「该做什么」；套用时刻判断哪些适用、哪些这次要改。
- **找不到文档时**：先走 `reference-breakdown` 拆出参考文档，再回来套用；没有匹配文档不妨碍做片，但不要凭空编「上次是怎么剪的」。
- **同一个人跨镜头一致**靠复用同一素材（定妆图/同一条镜头），不是重新生成。
- 套用落地后 `read_project_doc` 回读确认，别让文档和片子各说各话。
