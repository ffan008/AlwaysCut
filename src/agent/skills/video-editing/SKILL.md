# 图片视频混剪科普（Video Editing）

## 适用场景

科普、讲解、知识类视频：有口播或文稿，需要给每一句配上对应的图片、图表或视频片段，让抽象内容可视化。核心是「逐句配图」，画面跟着讲的内容走。

## 工作流

1. **拆句**：调用 `read_transcript`（或 `read_script`）把文稿拆成一句一句，拿到每句的词级时间。
2. **定配图**：每句判断该配什么——原理配图、数据配表、场景配实拍、概念配字卡；用 `search_media` / `search_stock_media` 找素材，没有就用 `submit_image` 生成。
3. **逐句铺画面**：用 `edit_item` 把图/视频按句子时间铺到对应区间，每句一个画面（或 2–3 句一个画面，视节奏）。
4. **加字卡**：讲重点/数据时用 `add_motion_graphic` 做字卡，把关键词「钉」在画面上。
5. **对齐与过渡**：用 `edit_captions` 让字幕跟句子对齐，`manage_effects` 加统一转场。
6. **收尾**：`normalize_loudness` 统一响度，`verify_export` 质检。

## 注意事项

- 画面要「真的解释」那句话，不是随便配张好看的图。
- 一句一画面太碎、一段一画面太死，按语速和内容密度取平衡。
- 字卡关键词要短、要跟嘴说的同步，别堆满屏。
- 版权素材用 `search_stock_media`，生成图注意风格统一（复用同一套提示词风格）。

## 交付前自检

- [ ] 文稿已逐句拆分，每句配图到位
- [ ] 画面与句子内容真实对应，无「图文两张皮」
- [ ] 字卡/字幕/转场对齐，节奏自然
- [ ] `verify_export` 通过
